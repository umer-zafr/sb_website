# SB Consultants — Official Website

> Modern, responsive official website and affiliate portal for **SB Consultants — Your Trusted Visa Partner** (Islamabad, Pakistan).

## 🚀 Features
- **Hero & Overview:** Interactive category showcase, mobile app highlights, and stats.
- **5-Step Application Milestones:** Synced with the mobile application workflow (Profile Review, Consultant Call, Ready Case, Embassy Submission, Feedback & Rating).
- **Direct WhatsApp Messaging:** Instant inquiry routing to official WhatsApp support.
- **Affiliate & Influencer Partner Portal:** Multi-step registration, live referral tracking, and automated promo code verification.
- **Legal & Compliance Policies:** Transparent Privacy Policy, Refund Policy (24-Hour Guarantee), Shipping & Delivery Policy, and Terms & Conditions.

## 📁 Project Structure
```text
├── index.html        # Main landing page & affiliate portal
├── assets/
│   └── images/       # Logos, phone mockups, category graphics
└── _redirects        # Netlify SPA routing configuration
```

## 🌐 Deployment
This website is optimized for static hosting platforms like **Netlify**, **Vercel**, or **GitHub Pages**.
- On Netlify: Deploy by dragging this folder directly into the Netlify Deploys dashboard or linking this repository.
